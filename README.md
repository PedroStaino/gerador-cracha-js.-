# Gerador de Crachá

Projeto desenvolvido para a atividade de Programação Web utilizando HTML, JavaScript e Git/GitHub.

## Objetivo

Criar um sistema para coletar informações do usuário que serão utilizadas na geração de um crachá.

## Coleta de dados

O programa solicita:

- Nome
- Sobrenome
- Ano de nascimento
- Se é aluno ativo da instituição

## Tecnologias utilizadas

- HTML5
- JavaScript
- Git
- GitHub

## Funcionamento

Ao abrir o arquivo `index.html`, o sistema utiliza comandos `prompt()` para solicitar os dados do usuário e `confirm()` para verificar se ele é aluno ativo da instituição.

## Organização do projeto

A atividade foi desenvolvida utilizando branches no Git para organizar o trabalho da dupla.

### Branch da coleta de dados

`feature-coleta-dados`

Responsável pela criação da estrutura HTML e pela coleta das informações do usuário.
